# 离线设计

应用只包含 Flutter 页面、Dart 本地文件与图算法、Rust 装配核心、打包的 Tranquility 静态数据。没有服务端工程、账户、SSO、市场页面、广告、推送、遥测、WebView 或远程更新入口。

## 运行时边界

```text
Flutter 装配编辑 ── Dart FFI ── Rust eve-fit-os ── 本地 Protobuf
       │
       └── Android filesDir 中的本地装配文件
Flutter 星图 ── 本地 JSON 星系/星门 ── Dart 路线搜索
```

Android main manifest 对 INTERNET 和 ACCESS_NETWORK_STATE 使用合并移除规则；debug/profile 不添加权限。构建后用 Android aapt 检查最终 APK，而不是仅检查源文件。唯一允许的包权限是 AndroidX 自动加入的 `org.evelocalstation.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`：它是保护内部广播的签名权限，不授予网络或设备数据访问能力。保留它避免削弱 AndroidX 的接收器保护；其他权限会导致离线审计失败。运行时不下载图片、字体、数据、许可证或引擎包。图形和图标由本项目绘制。

装配保存在应用私有目录，不申请共享存储权限。allowBackup=false 禁止应用数据自动备份。卸载会删除本地数据；用户应使用 EFT 导出保存重要装配。剪贴板只由用户点选导入/导出时使用，系统剪贴板自身的同步设置不由本应用控制。

## 构建阶段

开发机可以联网取得 Flutter、Cargo/Gradle 依赖和 CCP SDE。显式下载工具在 tools/ 中，且不打包进应用。数据转换器只读取本地输入，记录来源、构建号、SHA256。升级游戏数据要在开发机重建应用，第一版没有应用内自动更新。

eve-fit-os 的效果计算数据与用于选船/星图的官方 SDE 分开管理。缺少匹配的引擎数据时返回可读错误；不得以基础属性相加、随机值或演示结果冒充装配结果。pyfa 仅在开发机生成对照结果，不作为 APK 依赖。

0.2.0 的五个 PB2 与清单已经打包为 Flutter assets，来源与物品目录相同：官方 SDE 3494416。首次启动顺序写入私有目录的临时文件夹，Rust 校验所有 SHA256、引擎提交和补丁 ID 后才以原子重命名启用。版本目录重复使用前重新校验；损坏缓存从安装包修复。旧数据在新数据成功启用后清理，中断的临时目录在下次启动回收。全过程仅访问本地文件，不需要手机流量。

## 可验证的限制

- 星图只反映静态星门；不含临时虫洞、玩家跳桥、实时危险、主权或在线信息。
- 高安路线偏好基于静态安等，是路线成本规则，不是实时安全保证。
- 离线权限检查不能替代真机飞行模式测试。发布前仍须检查首次启动、保存恢复、导入导出和路线结果。
- debug 版本同样无 INTERNET，因此依赖设备网络套接字的 Flutter 调试/热重载能力可能不可用；使用单元和 widget 测试及安装包验证。

# 0.4.0 分类选择与模块复制

本版增加装备复制，并将舰船、装备、弹药和无人机选择改为可逐级浏览的分类列表。
分类来自已有的官方 Tranquility SDE，计算引擎与五个 PB2 数据文件没有改变。

## 模块复制

点击已装配模块，在操作面板中选择“复制一个”或“填满剩余同类槽位”。前者使用当前
同类槽位中最靠前的空位；后者依次尝试剩余空位。复制保留物品 ID、模块状态和弹药，
每个副本独立，修改一个不会改变其他副本或原模块。已有模块不会被覆盖。

复制前会检查原模块、槽位、状态及弹药是否有效。连续复制时，每个新增模块都参与后续
炮台/发射器挂点与模块组数量检查；达到限制时保留已成功加入的副本，并说明停止原因。
槽位已满、原模块不兼容或无法识别时说明原因，不凭空产生物品。子系统按其独立系列规则
处理，不允许复制同类子系统；防御性上限为每类八个槽位。

CPU、电网、技能和效果仍由真实本地引擎重新计算，复制功能不使用静态估计代替这些结果。
新副本作为未保存修改处理，保存、重命名和国际服英文 EFT 导入导出继续使用原有流程。

## 分类选择

新增 814 个与本版物品有关的官方分类节点及其父子关系。可按“舰船 → 护卫舰 → 标准护卫舰
→ 米玛塔尔”查找裂谷级，或按“舰船装备 → 炮台和发射器 → 射弹炮台 → 自动加农炮 → 小型”
查找小型自动加农炮。中文名称缺失时使用官方英文名称，不自行编造类别。

分类行显示可选物品数量，进入后可使用路径导航和返回操作；没有可选物品的分支不会
占据列表。还可切换“全部物品”，或在任何层级输入中文、英文、分类别名或 ID 搜索当前
选择器的全部候选物品。清空搜索后继续原来的分类位置。

候选物品只经过单一路径时自动略过中间层级；手动点击路径后，返回操作仍逐级向上，
不会突然跳回自动选中的最末级。开发中的独立检查发现了这一返回跳转问题，已修复并
加入回归测试。

装备和弹药继续保留兼容筛选，关闭筛选时可查看具体不兼容原因。113 个没有官方市场分类
的已收录物品仍可通过“未分类”和搜索找到：3 艘舰船、100 个模块、1 种弹药、9 种无人机。
分类元数据只用于本地浏览，不引入市场价格、订单、账号或网络请求。

界面参考用户希望的分类选择方式，列表、导航及操作代码由本项目实现。没有使用旧 APK
中的代码、数据库或素材，也没有把未经核实的第三方截图当作原版精确设计。

## 验证范围

独立模块复制测试 9 项通过，覆盖真实 Vexor 与 Drone Link Augmentor I 的单次/填满复制，
携带弹药的过载炮台、独立副本、连续挂点/模块组限制、满槽/子系统拒绝、八槽上限、非法
或过期来源、无副作用，以及本地保存和英文 EFT 往返。限制边界使用明确标注的合成夹具，
不把测试数据当作游戏计算结果。

另有 3 项模块复制界面测试通过，覆盖复制/填满后的一次批量重算、本地保存及英文 EFT，
携带弹药和过载状态的独立副本，以及拒绝无效复制时保持装配和计算次数不变。

分类选择器 4 项界面测试通过，覆盖不输入名称即可沿真实官方舰船路径选择裂谷级、全局
搜索后恢复分类、未分类物品可选择、兼容筛选切换，以及自动起始层级之上的返回路径。
在 360 × 720、1.3 倍文字和 280 dp 键盘遮挡场景下完成搜索和选择，无布局溢出。
3 项选择器与操作面板预览测试通过，覆盖 390 × 844 与 360 × 720、1.3 倍文字及模拟键盘
遮挡，并使用真实本地引擎计算的 Vexor 装配渲染复制菜单。已独立检查生成的
[舰船分类](previews/ship-picker.png)、[装备分类](previews/module-picker.png)和
[复制操作](previews/module-copy.png)截图，主要分类、返回入口与四个操作均可见，未发现
文字重叠或操作被裁切。

这些是 Flutter widget 检查，不等同于实体手机测试。最终完整测试结果、截图、安装包
摘要及离线权限审计见 [BUILD_REPORT.md](../BUILD_REPORT.md)。
原有 132 项 pyfa 对照结果对应未改变的引擎和数据，本版不扩大其已验证范围。

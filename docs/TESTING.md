# 0.5.0 星图体验试用说明

这一版只需安装 APK。计算数据和中文名称已内置，不用注册、配置数据目录或另外下载资源。
适用 Android 7.0 及以上的 ARM64 手机；当前为预览签名，尚未做真机验证。

本版重点是星图。缩放后星系点仍保持小尺寸，点周围也可以选中；可用双指或右侧加减按钮缩放。
顶部提供起终点交换和显示设置，路线栏的方框按钮可切回全部星门并适配整条路线。
窗口或路线栏高度变化会保留已有中心和缩放；切换星域或主动重置才重新适配。
选中星系后打开“星系详情”，查看星座、行星数量、恒星光谱及相邻星系；点邻居可继续定位。
详情可复制英文名、查看星域或设置绕行。路线详情支持复制英文路线；搜索会保留本次会话最近六项。

建议先观察全图拖动、放大到局部后拖动，以及横竖屏切换。电脑侧性能测量不能代替手机帧率；
反馈卡顿时附手机型号和所处视角（全图/局部/显示名称），更容易定位问题。

保留上一版的模块复制和分类浏览。点模块名称打开菜单，选择“复制一个”或“填满剩余同类槽位”；
弹药和状态会一起复制，已有装备不会被替换。达到挂点或数量上限时会显示原因。
选择舰船和装备时可以逐级点开官方分类，也可以直接搜索或切到“全部物品”。
搜索覆盖当前候选物品的全部分类；清空后回到原分类。“未分类”保留没有官方分类的物品。

常用统计固定在装配顶部，点开摘要查看完整属性；
通过槽位分类直接跳到高槽、中槽、低槽、改装件或无人机，点击装配名称打开本机装配列表。
英文名称仍可搜索，导出的 EFT 继续使用国际服英文名称。已有装配的自定义名称不会被自动改写。

方便测试时，可以按以下顺序操作：

1. 开启飞行模式，首次打开应用，等待本地数据准备完成。
2. 新建裂谷级（搜索 Rifter 也可），使用全技能 V，加入 200mm AutoCannon II 和 EMP S，查看中文物品与顶部常用数值。
3. 切换模块状态、添加推进器或无人机，检查数值变化；被动装备会使用适合的工作状态。
   对同一种武器尝试“复制一个”和批量填充，检查已装弹药、模块状态、槽位和挂点限制。
4. 保存装配，退出并重新打开，确认装配仍在；复制 EFT 后再导入，核对舰船、装备和弹药。
5. 在星图搜索吉他 / Jita 和艾玛 / Amarr，比较最少跳数与高安偏好路线，尝试避让一个星系和缩放星图。
6. 使用手机的大字体设置，检查长名称、槽位操作和属性面板是否容易阅读、点击。

首批 12 组装配的 132 项核心指标已与同版数据的 pyfa 独立结果对照通过。
这些检查涵盖常见资源、伤害、过载、推进和无人机行为；电容、复杂抗性、特殊武器、T3 完整
数值与其他特殊效果仍需扩大对照。市场、账号、后台、广告和联网功能没有启用。

EFT 文本不会完整保存技能模式和所有工作状态；应用本地保存可保留这些设置。
卸载会删除本机装配，重要配置可先复制 EFT 留存。星图只有静态星门，不反映实时危险或临时虫洞。

反馈时给出手机型号、Android 版本、操作步骤，以及相关装配的 EFT 即可。
若是数值不同，再注明技能模式、模块状态、弹药、出战无人机和用于比较的 pyfa 数据版本。

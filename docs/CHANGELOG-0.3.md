# 0.3.0 中文紧凑界面

本版把装配操作和常用属性放到手机屏幕前部，使用官方中文名称。计算仍由本地 Rust
引擎完成，市场仅保留接口，没有新增在线功能。最终安装包、签名、权限审计和完整测试
记录见 [BUILD_REPORT.md](../BUILD_REPORT.md)。

## 中文名称与兼容性

中文来自已经缓存的 CCP Tranquility SDE build 3494416 的 `name.zh`，没有另行下载
数据或使用旧 APK 的数据库、素材、代码。界面默认简体中文，标准对话框也使用本地化资源。

| 内容 | 官方中文字段覆盖 | 回退方式 |
|---|---:|---|
| 舰船 | 423 / 423 | 缺失时保留英文 |
| 模块 | 4,019 / 4,021 | 两项没有官方译名，显示英文 |
| 弹药 | 1,017 / 1,017 | 缺失时保留英文 |
| 无人机 | 154 / 154 | 官方字段中的拉丁编号照原样显示 |
| 物品分类 | 280 / 280 | 保留英文分类作为检索别名 |
| 星系 | 8,490 / 8,490 | 保留官方代码和编号 |
| 星域 | 114 / 114 | 保留官方代码和编号 |

“有中文字段”不意味着每个名称都含汉字：星系中有 1,983 个与英文名称不同，许多零安、
虫洞和编号名称在官方中文数据中仍使用拉丁字符。应用不会为这些名称编造译名。

显示名称与物品身份分开处理。舰船、装备、弹药、无人机、星系及星域支持中文、英文、
分类或 ID 检索。EFT 继续使用国际服英文物品名称；中文装配标题可正常导入导出。
本地装配的 ID、物品数字 ID、槽位、状态和用户自定名称保留，不需要迁移保存文件。
旧的自动英文装配标题可以显示为中文，但不会据此重写已保存的数据。

## 装配与星图布局

装配页移除大幅装饰区域和多层卡片，改用舰船/保存工具栏、四项属性摘要和可滚动槽位表。
常用操作保留在手边，完整统计、技能假设、装配提示和详细模块操作放入可滚动面板。
槽位多的舰船可筛选高、中、低槽、改装件、子系统及无人机。

模块行使用中文主名称；过长名称省略显示，点击后可查看完整中英文名称、更换装备或弹药、
卸载弹药和查看计算属性。带弹药的行保留弹药名称。状态选择与移除操作有各自的点击区域，
没有将小图标尺寸当作可点击范围。移除子系统后超出槽位的装备继续保留，方便调整。

界面尺寸和检查结果：

- 应用顶栏 48 dp，装配工具栏和属性摘要各 52 dp，底部导航 56 dp。
- 不带弹药的槽位行 44 dp，带弹药的行 52 dp；状态菜单及移除按钮至少 44 × 44 dp。
- 390 × 844 的测试视口中，默认字体及 1.3 倍字体都能完整显示至少 9 行槽位，无布局溢出。
  同尺寸的真实计算截图可完整看到三行高槽、三行中槽和四行低槽。
- 装备列表单独滚动，舰船工具栏和属性摘要保持可见；筛选后回到该组列表顶部。

独立检查发现并修复了三项具体问题：T3 原始舰体的无人机舱为零时仍保留无人机编辑入口，
避免装上增加舱容的子系统后无法添加无人机；完整属性面板保留起跳时间和含装填 DPS；
电容达到模拟上限且没有稳定标记时，也能显示真实的“未判定为稳定”状态。

星图的中文名称用于搜索、星域筛选、路线详情和地图标签；路径计算、起终点、绕行条件
仍使用原有数字 ID。手机上的起终点并排显示，绕行名单集中管理，保留更多地图空间。

## 验证边界

本版的数据和界面测试检查中文回退、中英文及 ID 检索、英文 EFT 往返、旧装配身份、
槽位与状态操作，以及手机布局。12 项装配/统计界面测试通过，覆盖上述密度、T3 无人机、
电容边界、未保存提示、保存/重命名、模块操作和 EFT；另有中文界面与数据测试。
已独立查看真实原生计算产生的手机装配页和属性面板截图，未发现内容重叠或假造统计值。
这些是 Flutter widget 渲染检查，不等同于已在实体手机上完成测试。最终全量测试数量、
APK 审计和截图记录以构建报告为准。

原生引擎、固定上游代码和五个 PB2 数据文件没有改变。0.2.0 已完成的 12 组装配、132 项
独立 pyfa 比较仍适用于相同引擎和数据；本次界面改动没有扩大这一验证范围。
电容、逐层抗性、射程和特殊效果仍不能概括为全部通过 pyfa 验证。

全程复用现有 SDK、依赖与游戏数据缓存。应用运行不需要服务器、账号或联网权限，
没有新增遥测、广告、WebView 或远程字体。
